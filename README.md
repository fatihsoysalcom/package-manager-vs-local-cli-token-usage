# Package Manager vs Local CLI Token Usage

This Python script simulates the overhead of loading many items via a hypothetical package manager (MCP) versus individual local CLI tools. It demonstrates how the internal processing of a package manager can lead to a higher 'cost' (represented by simulated time/work) compared to direct CLI invocations, mirroring the token consumption difference discussed in the article.

## Language

`python`

## How to Run

Run the script using: python token_comparison.py
